Crops and resizes a face region from bitmap.

Extracts the face region using the bounding box from face detection, then resizes it to a square of specified size for model input. Applies boundary checks to prevent out-of-bounds cropping.

Parameters
bitmapSource bitmap containing the face
faceFace object with bounding box coordinates
sizeTarget size for the output square bitmap (default: ImageDefaults.FACE_CROP_SIZE)
Returns
Bitmap Cropped and resized face bitmap

Converts grayscale bitmap to normalized float buffer for TensorFlow Lite

Extracts pixel values from grayscale bitmap and normalizes them to [0, 1] range by dividing by ImageDefaults.NORMALIZE_DIVISOR (255.0). This matches the Python preprocessing pipeline: face_norm = face_resized / 255.0

Logs preprocessing statistics periodically for debugging purposes.

Parameters

Returns
ByteBuffer Buffer containing normalized float values in native byte order

Main pipeline for processing camera image and detecting emotion

Complete emotion detection pipeline:

  1. Detect largest face in the image using ML Kit
  2. Convert ImageProxy to grayscale bitmap
  3. Crop and resize face region
  4. Normalize pixel values to [0, 1] range
  5. Run TensorFlow Lite model inference
  6. Return emotion label with highest confidence
Parameters
imageImageProxy from CameraX containing the camera frame
tfliteTensorFlow Lite interpreter with loaded emotion model
onEmotionDetectedCallback invoked with detected emotion label string
